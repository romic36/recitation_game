# recitation_game
Recitation Game — CE Grades 7–10

How to Use:
1. Open 'recitation-game.html' in any modern browser.
2. Use the dropdown to select a grade level.
3. Click "Show Question" to begin.
4. Use "Reveal Answer", "Next Question", and "Show All Answers" as needed.

This tool is optimized for classroom projection and assistant training.

To edit questions, open 'recitation-game.jsx' in a code editor.
